# software events and iret

## purpose

Execute guest software event entry and interrupt return through the existing imported execution contexts and checked private memory. A guest installs descriptor roots and a task register, executes INT, runs a handler on the selected stack, and returns with IRET. Cover real, protected, virtual-8086, compatibility and 64-bit execution, including privilege changes and IA32e IST.

This builds on [system flags and instruction boundaries](../system-flags-and-instruction-boundaries/spec.md), [descriptor tables and segment loads](../descriptor-tables-and-segment-loads/spec.md), [far control and code segments](../far-control-and-code-segments/spec.md) and [memory map and code validity](../memory-map-and-code-validity/spec.md). Detection of existing faults/traps still returns its typed controlled exit. It does not automatically enter an IDT handler. External IRQ/NMI, delivery escalation/#DF/shutdown, hardware task switching, call/task gates, CR/paging/reset transitions, VME/PVI, VMX, CET and FRED are separate work.

## instructions and state

Select `CC` INT3, `CD ib` INT imm8, `CE` INTO outside long64, `F1` INT1, `CF` IRET and `0F 00 /1,/3` STR/LTR. INTO with OF0 completes normally without reading IDT/TSS/stack. INT3/INTO/INT1 are distinct from `CD 03/04/01`: all three bypass virtual-8086 IOPL admission; only INT1 bypasses gate DPL and uses EXT1 in delivery error codes. INT imm8/INT3/INTO use EXT0. Software entry never adds an exception error-code slot, including INT14.

IRET uses effective operand16/32 outside long64 and default32/66-selected16/effective REX.W-selected64 within long64. `66 48 CF` is64 and `48 66 CF` is16. LTR reads fixed16; STR memory writes16 while its register forms use the inherited selector-store width/alias rules. Required selected bytes precede execution. Segment/address prefixes do not redirect implicit frame accesses. F2/F3 are ignored for these selected forms; inherited mixed/repeated group1 unsupported frontiers remain. Sole LOCK is invalid after selected instruction tails, before operand access. INTO in long64 and LTR/STR in real/virtual8086 retain the appropriate private invalid-encoding frontier.

Add a detached task-register snapshot `tr: {selector, valid, base, limit, attributes}` to execution-context output. Widths/raw attribute representation match LDTR: u16 selector, boolean valid, u64 base in IA32e/u32 otherwise, u32 expanded limit, u12 attributes. Full context input may omit TR and gets an all-zero invalid cache; explicit malformed/undefined/null TR rejects atomically. The presence of `tr`, even with undefined value, selects full-snapshot validation. Legacy context shorthands remain compatible. Omission never inherits the previous TR. This is an import default, not a hardware-reset image. Bounded raw attributes are retained; instruction consumers validate usable type/limit. No TSS memory is fetched during import, export or ordinary execution. Mode remains the sole VM authority; scalar FLAGS input still excludes VM.

LTR validates CPL0 and a nonnull GDT selector, available TSS type1/9 in legacy protected mode or9 in IA32e, descriptor presence and the complete selected descriptor, including high-base/reserved/canonicality checks. It installs the captured cache with post-busy type3/B and marks the descriptor busy only after all selected private effects are admitted; other captured attributes are retained. Busy TSS, TI, null, malformed descriptor and late denied busy write leave old TR and bytes unchanged. STR reads the cached selector without fetching GDT/TSS memory. LTR does not inspect stack pointers, IST or the I/O bitmap.

LTR pre-admits read/write access to the complete selected descriptor span for its busy-bit RMW. The single private-memory CPU then writes the captured access byte with the busy bit set. Only the actual byte change participates in backing-aware code invalidation; this does not claim shared-vCPU locked atomicity.

## software event entry

Real mode reads the four-byte IVT entry selected through IDTR, with vector bounds checked first. It prepares the fixed16 FLAGS/CS/next-IP frame on the old stack using its loaded pointer width. It loads the target selector/base without a GDT lookup and preserves the inherited real-mode hidden-cache behavior. Saved FLAGS include the post-begin, pre-delivery image; live TF, IF, AC and RF clear under the selected real entry rules. Real INT performs no extra target-limit admission: it publishes the frame/target and any retained-CS-limit failure belongs to later handler fetch. Real IRET separately checks its return target against the retained CS limit and reports #GP0 before publication.

Legacy protected entry reads an eight-byte interrupt/trap gate. Type6/7 selects16-bit frame slots; typeE/F selects32-bit slots, independently of caller operand prefixes. Validate IDT bounds/type, software DPL, presence, nonnull code selector, code type/privilege/presence in architectural order. After code type/privilege/presence, prepare any TSS/new-SS state and frame geometry, then check target limit before write admission. Task gates remain Unsupported before task-body access. A conforming target keeps CPL; a nonconforming target may enter the same or a more privileged CPL. Same-CPL entry uses old SS:SP. Inner entry reads the selected SP/SS pair live from the cached16/32-bit TSS, validates the new stack with #TS/#SS distinctions, and adds old SS/SP to the frame. The gate's slot width and old/new stack-pointer widths are independent.

Virtual-8086 INT imm8 with IOPL<3 reports #GP0 before delivery, with VME disabled. INT3/INTO/INT1 bypass that check. Admitted delivery uses the protected gate path and a CPL0 handler, pushes the nine gate-width slots GS, FS, DS, ES, SS, SP, FLAGS, CS and next-IP, and sets ES/DS/FS/GS selector0 and usable=false, retaining their other raw cache facts/attributes under the inherited implicit-clear profile. It saves VM1 from the context and clears live VM by entering protected mode. IOPL/VM are not copied into a second scalar authority.

IA32e entry reads the complete16-byte IDT interrupt/trap gate and requires a64-bit code target. Use S0, gate typesE/F, IST bits0..2; the selected reserved-field admission requires bits3..7 of byte4 and bytes12..15 zero, otherwise #GP(IDT error). IA32e type6/7 gets the chapter7.14.1 special #GP0 before DPL/presence; other invalid kinds get #GP(IDT error). A non64 code target (L0 orD1) gets #GP(IDT error), distinct from a malformed/noncode code descriptor selector error. These choices pin the instruction-algorithm/chapter-specific distinctions explicitly. DPL, presence, selector and canonical target rules are checked before publication. IST1..7 selects the live TSS IST qword even at unchanged CPL. With IST0, an inner-CPL entry uses the live RSPn qword; same-CPL entry retains old RSP. Align the selected stack to16 before preparing the frame. All IA32e entries push five qword slots: old SS, old RSP, FLAGS, CS, next-RIP, including same-CPL and compatibility callers. Stack-switch iff target CPL is inner or IST is nonzero. Same-CPL IST0 preserves the complete old SS, also for a compatibility caller. A switch installs null selector=new CPL, retains the old raw SS cache except usable=false, and retains old attributes except DPL=new CPL. This deterministic private snapshot profile does not claim that hardware exposes all retained hidden bits.

Before a selected TSS use, the imported raw-cache policy requires valid, nonnull GDT selector, S0/P1 and busy type3 for legacy16 orB for legacy32/IA32e64. Wrong or unusable imported cache reports #TS(TR selector with EXT) before memory; an unchanged-CPL non-IST path does not inspect TR. Check the complete selected TSS-field limit before reads. Legacy privilege-stack capture reads SS first, then SP/ESP: type3 SP at `2+4*CPL` and SS at `4+4*CPL`, typeB legacy ESP at `4+8*CPL` and SS at `8+8*CPL`, with SP widths2/4 and SS width2. IA32e RSPn is at `4+8*CPL`, ISTn at `36+8*(n-1)`, each width8. Noncanonical in-range TSS field spans report #TS(TR selector with EXT); a noncanonical loaded new RSP/frame span reports #SS(EXT) before private mapping.

Gate/TSS fields are captured before A/frame writes, including aliases with each other and with executable bytes. TSS stack/IST fields are read at every entry from the loaded TR cache; changing the GDT does not reload TR and changing the TSS body does not require LTR. Read only selected fields, with complete field spans and cached limit checks, not the whole TSS or unselected stacks.

On successful protected/IA32e entry, save the post-begin FLAGS image then clear live TF, NT, RF and VM. Clear IF only for an interrupt gate; trap gates preserve it. Preserve other selected system/arithmetic flags. Software entry suppresses the ordinary incoming-TF completion trap, retires once and publishes the handler context/PC. It consumes the prior private interruptibility interval and leaves both histories clear. INTO OF0 uses the ordinary completion/TF rules instead.

## interrupt return

Prepare selected return slots from the old SS and pointer width before publishing PC, SP, FLAGS or context. Slot i begins at `(oldSP + i*operandBytes) modulo oldStackWidth`; each complete slot is a nonwrapping access. Same-stack advancement merges the final masked pointer into the original raw SP. A restored SP slot instead zero-extends the popped operand-width value into raw SP, without inheriting the unrelated old raw high bits or truncating it again to the new active stack width. For B16/W32, a frame beginning at FFF0 visits FFF0, FFF4, FFF8, FFFC, 0000 and onward, rather than one contiguous span. Attempt each slot geometry then its private read before moving to the next slot: an earlier unmapped IP beats a later CS-slot segment-limit failure. Capture initial IP/CS/FLAGS, select and validate the return branch/code, then capture required extra slots, validate restored SS, target geometry and A-write admission. VM return takes its complete extra slots without a protected code-descriptor lookup. Distinguish source mode, target mode, operand width and restored stack width. Validate complete source slots, code/stack descriptors, privilege/type/presence and target geometry; do not require mapped destination instruction bytes or an immediate data access at the restored SP.

Real IRET16/32 restores the selected IP/CS/FLAGS image and updates the real CS base without fetching GDT memory. Use Intel's real32 writable/preserved FLAGS masks rather than POPF masks. Returning within virtual8086 requires IOPL3 before stack access and retains VM, IOPL, VIF and VIP according to its width-specific rules.

Legacy protected NT1 selects the unimplemented task-return frontier before ordinary frame access. IA32e NT1 reports #GP0 before frame access. Ordinary protected/compatibility returns validate the saved code selector and permit same/outer CPL only. An outer return additionally captures SP/SS and validates/installs the destination stack, then invalidates ES/DS/FS/GS whose selector is null or whose cached DPL is below the new CPL for data/nonconforming code. Set selector0 and usable=false while retaining other raw cache facts; the null-selector predicate applies even to otherwise usable imported raw caches and is distinct from the inherited far-return predicate. Same-CPL returns normally consume three slots. If IRET began in long64, it additionally restores SS:SP even at unchanged CPL, including a compatibility target; a compatibility-source same-CPL return does not acquire those extra slots just because its target is long64.

For protected IRETD at old CPL0 with saved VM1, capture the complete nine-dword frame, validate the real16 return-IP bound and restore virtual8086 CS/SS/ES/DS/FS/GS caches, CPL3, SP and FLAGS together. Each restored VM cache has selector, base=selector<<4, limitFFFF, D0, usable=true and type read-write (including CS), with DPL3, present/accessed=true and conforming/long/granularity/available=false. IRET16 cannot set VM. VM remains clear on IA32e returns. A null restored SS is admitted only for a long64 target with new CPL!=3 and selector RPL==new CPL; otherwise #GP0. Admitted null SS retains its raw hidden cache and marks it unusable, as the inherited far-return private profile. A nonpresent restored nonnull SS reports #SS0, distinct from entry stack-selector error codes. Retain wide/raw FS/GS cache facts under the inherited inaccessible-cache policy. Do not probe or precheck canonicality of the unused restored SP value: a later stack access owns that failure.

IRET FLAGS permission uses old CPL and old IOPL. Restore arithmetic flags/TF/DF/OF/NT as selected; RF/AC/ID require32/64; IF requires old CPL<=old IOPL; IOPL requires old CPL0; VIF/VIP are restored by32/64 only at old CPL0. Preserve reserved bits and constant bit1. Incoming TF sampling remains distinct from TF newly restored by the frame: newly enabled TF applies to the following instruction; incoming TF1 still traps after a completed IRET even if its frame clears TF, with the prepared returned context/continuation. Restored RF must survive the completed IRET until the next instruction's begin phase. Successful return consumes the prior history without creating an SS-load shadow.

## publication, diagnostics and code ownership

These operations use checked private memory. Capture selected reads and pre-admit every A/busy/frame write before any private write or context/state publication; late private admission failure does not leave half a frame or half-installed context. Publish captured A/busy bytes before frame slots in architectural push order, so overlapping slots and descriptor/frame aliases have explicit deterministic effects. This extends the inherited private far-transfer admission policy; it does not assert recoverable hardware microcode footprints or automatic nested-exception delivery.

An instruction that has begun clears incoming RF before ordinary operand/descriptor/privilege failures under the existing boundary contract. Private required-fetch/decode-unsupported/invalid/resource frontiers remain before begin. A selected INT that discovers an unimplemented task gate after a gate read, or a legacy NT IRET that selects task return, has already begun: preserve history and other state but do not resurrect cleared RF. Validate applicable gate DPL/presence before the task-body Unsupported frontier; never access the unselected task body. Failed entry/return does not retire or consume SS/STI history. Successful transfers update context version when loaded execution facts change, invalidate executable backing dependencies after actual writes, and redispatch before any successor. Entry budget/stop gates prevent work; post-transfer budget and stop-at-destination occur before handler/resumed instruction fetch. No predecessor GPR/FLAGS/XMM or pending numeric state may be replaced by a stale canonical bank.

Preserve existing diagnostic IDs. Architectural admission failures reuse protection records with exact vector/error code/phase and selector provenance; legacy stack limit/unusable/type failures retain the inherited private SegmentFault with prepared geometry, and private map failures retain their access record. These private geometry records do not claim an architectural #SS error-code projection. The explicitly selected IA32e canonical TSS/new-RSP/frame failures use the #TS/#SS protection codes above. Extend system-memory provenance as a discriminated union: GDT/LDT carry selector and phase descriptor-read/descriptor-accessed-write/descriptor-busy-write; IVT/IDT carry vector, no selector, and phase gate-read; TSS carries cached TR selector, no vector, and phase tss-read. Existing GDT/LDT record shapes remain compatible. System attempts form legacy starts modulo2^32 with nonwrapping field endpoints, or widened IA32e base+offset with nonwrapping spans. Widened overflow is a private address-range attempt, never a wrapped read at0; in-range TSS canonical failures use the architectural #TS rule above. Include widened address, requested width/access, failing address and source instruction PC. A failed destination-stack attempt describes prepared destination geometry while the published context remains old. Detection returns to the caller; it does not recursively deliver the new exception.

No per-instruction event polling, TSS reads, host import or extra control validation is added to ordinary code. Add only the helper/import and state lifetimes consumed by the selected operations. Keep current generated entry ABI, numeric offsets, resource bounds and five-argument invocation intact. Full context snapshots produced by entry, LTR and IRET must import again without losing raw loaded facts.

## acceptance packets

Use independently authored bytes, descriptor/frame literals, Rust semantic/decode tests and shared actual generated-Wasm Node/Chrome scenarios. Check full GPR/FLAGS/history/context, XMM/MXCSR/raw-pending x87, guarded bytes, allowances, typed diagnostics and source/resource lifetimes.

1. All selected opcodes and widths: effective/cancelled REX, ignored prefixes, selected tails, sole LOCK, INTO long64, LTR/STR forbidden modes, extended registers and memory STR's exact two-byte write. Unsupported task gates/NT paths do not probe unselected task memory.
2. TR old-input compatibility, detached output, malformed imports and reentrant getters. Omitted TR clears the prior cache; bounded invalid raw facts round-trip; no GDT/TSS read occurs during snapshot. Existing scalar/run reentrant protections and context ordering remain intact.
3. Actual LTR/STR: legacy16/32 and IA32e16-byte descriptors, busy byte and full captured cache, same selector after GDT mutation, unavailable/busy/TI/null/absent/reserved/noncanonical cases, denied high tail/busy write, descriptor/TSS/code aliases and write-only busy-byte aliases. TSS body may be unmapped at LTR.
4. Real IVT entry and IRET16/32: exact FLAGS/CS/IP slots and guard bytes, loaded SS.B16/32, raw SP preservation/wrapping, nonzero IDTR/CS/SS bases, IVT limits, target/stack failure ordering and repaired resumption. Prefix66 does not turn real INT into IRETD's frame.
5. Protected interrupt/trap gates16/32 from both CS.D profiles: gate width controls slots; distinct IF effect and saved FLAGS; CPL/RPL/DPL/conforming and presence/error-code ordering; INT1 gate-DPL bypass and EXT1 versus INT3/INTO/CDn.
6. CPL3 INT→CPL0 handler→outer IRET with exact TSS field widths and frame slots. Change the TSS SP/SS body between entries without LTR and change the GDT without changing the loaded TR. Failed new stack selector/presence/geometry/map access preserves all prior state and memory.
7. IA32e same-CPL and inner-CPL five-qword frames, RSP16 alignment, IST1 and IST7, IST overriding RSPn, null SS installation and restored raw old RSP. Include compatibility-source INT into64 and IRET back, exact source-width/tail boundaries and unselected TSS fields unmapped.
8. Long-source IRET16/32/64 same-CPL and outer targets, including long→compat and compat→long; literal three-slot/five-slot contrast detects wrong source/target-mode reasoning. Noncanonical target PCs versus unused noncanonical restored SP, null SS and inaccessible data-cache clearing are distinguished from later destination fetch/data failures.
9. Virtual8086 CDn IOPL refusal versus INT3/INTO/INT1 bypass, CPL0 gate restrictions, nine-slot save/clear and IRETD VM return. Deny the final GS source slot, then repair; no partial VM/context/FLAGS publication. VM stays context-owned and round-trips.
10. IRET flag-mask literals distinguish old/new CPL/IOPL, VIF/VIP, NT, RF, AC, ID, reserved bits, real32 preserved bits and16-bit upper preservation. Incoming/new TF and restored RF are tested separately from ordinary POPF behavior.
11. INT under TF enters the handler without an extra #DB. IRET restoring TF then a resumed ordinary instruction traps at that instruction's boundary, including a single public run spanning handler execution. INTO OF0 can step normally and reads no event memory. Event success/failure across existing SS/STI histories has exact preservation/clear behavior.
12. Live predecessor GPR/arithmetic/system FLAGS/XMM work survives helper success and every late failure. Existing pending x87/#MF does not turn INT/IRET into waiting numeric instructions. No numeric image or status changes.
13. Split/guarded frame slots, private-map tail failure, canonical/u64 boundaries, descriptor A/busy and source/frame aliases, overlapping push slots and backing-executable aliases. Failed pre-admission never mutates bytes or owner generations; successful alias writes invalidate before continuation.
14. Destination budget/stop before unmapped fetch, retained-middle entries, code/context mutation during async compilation, source/profile mismatch, eviction and warmed repeated handler/return loops. Unchanged-context loops reuse stable artifacts without per-trip recompilation growth. Guest context changes retain the existing conservative context-version invalidation policy; characterize their compilation/resource cost separately and prove that a resource refusal cannot erase a completed transfer or replay its frame.

## verification and performance

`npm run check` is the acceptance command. Semantic/decode, generated-Wasm, transport and public tests stay with their behavior owners. Use `cargo test --locked`, `npm run typecheck` and focused Node/public scenarios at logical checkpoints. Follow existing Rust/TypeScript style, run formatting/lint and commit concrete verified slices. Add no dependencies or generic event framework.

Compare all104 inherited checked workloads against source525876c on matched Node/Chrome inputs and observations. The added context output is normalized explicitly for old snapshots without hiding prior field changes. Characterize LTR/STR, INT/IRET same/inner CPL, real/legacy/IA32e, IST, VM return, diagnostic latency, one-instruction public resumes, context churn and backing aliases separately. New instructions are current-only when the old build rejects them. Record creation, translation, compile/instantiation, first completion, early/later reuse, native entries, dispatches and generated/cache bytes. Investigate material outliers with fresh/reverse/A/A controls; keep unavailable and sub-tick comparisons explicit. Distinguish synthetic checks from application throughput and shared-process first completion from independent cold starts.

Implementation checkpoints are context/TR authority and its consumers; selected decode and LTR/STR; gate/TSS/frame entry; return/VM/FLAGS semantics; generated helper publication and boundary integration; independent conformance/review and matched performance. Maintain one semantic owner for descriptor/frame/return admission, including generated paths. Research, audit and measurement records live in the Ring64 Obsidian bank; formal specs and executable tests live here.
