# fast system transfers

## objective and chosen vertical

Implement complete Intel-style IA32e fast system entry and return: SYSCALL/SYSRET, SYSENTER/SYSEXIT, SWAPGS and the selected MSRs that they actually consume. A guest programs its entry state, enters a CPL0 handler from CPL3, obtains its kernel stack through GS, performs protected work, and returns to Long64 or compatibility code. Fault repair, debug/event boundaries, changed translations and suspension must preserve that entire execution story. MSR storage or one successful SYSCALL is insufficient.

The baseline is `8a7ee067bb9d036b4d19434458706490506ce44a`. It already implements imported mode/loaded-segment state, ordinary far transfers, supervisor/event stacks, selected exception/IRQ/NMI delivery, hardware debug and four-level IA32e paging. It does not implement these fast transfers: EFER.SCE is fixed0, RDMSR/WRMSR select only EFER, and live FS/GS bases belong to `ExecutionContext`. This spec deliberately evolves those frontiers without implying reset, boot, general MSR coverage or a complete processor identity.

The CPU-wide scope remains the thirteen architectural areas in [the index](../index.md). Independent candidate review selected this vertical for the following reasons:

| candidate                  | dependency closure and decision                                                                                                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| fast system transfers      | paging, privilege caches, faults and instruction boundaries now exist; closes a substantial user/kernel loop across them. Selected.                                                                     |
| x87 special functions      | coherent independent numeric work remains: remainder/exponent operations, transcendentals and packed BCD. Requires a deliberate raw80 accuracy/oracle contract; strongest next alternative.             |
| imported legacy/PAE paging | useful for protected execution, but needs another coherent control/address family, walk formats and implicit-system consumers. Retain as a separate candidate.                                          |
| reset and mode transitions | current memory model is immutable and paged contexts remain IA32e; PE/PG/PAE/LME transitions require an explicit execution-family lifecycle. Combining that redesign here would obscure both contracts. |
| extended state / identity  | XSAVE needs enable masks and real component consumers. CPUID or a generic control/MSR bank alone would report or store state without completing another execution path.                                 |

Planning assumptions: retain private-linear execution unchanged; add this behavior to the existing `ia32e-paged` profile; select Intel semantics, canonical48 and existing fixed controls, without AMD compatibility SYSCALL/CSTAR behavior. These are explicit profile choices, not claims about every x86 processor. Internal implementation checkpoints do not narrow the complete scope below.

## profile and public state

Fast-transfer instructions and the selected MSRs become available automatically on `ia32e-paged` CPUs. No additional feature switch is needed. EFER.SCE still controls SYSCALL/SYSRET at execution time; it does not control SYSENTER/SYSEXIT or SWAPGS. The existing private-linear CPU retains its current unsupported-instruction/required-fetch frontiers, imported profiles and host API meanings; do not manufacture a PG0/EFER image for it.

Add an optional `fastSystem` constructor field and idle `readFastSystemState()` / `setFastSystemState(state)` on paged CPUs:

```ts
interface FastSystemState {
  star: bigint;
  lstar: bigint;
  fmask: bigint;
  sysenterCs: bigint;
  sysenterEip: bigint;
  sysenterEsp: bigint;
  kernelGsBase: bigint;
}
```

Omission initializes all seven fields to0, without reading guest memory. An explicitly supplied value must be a complete record of primitive unsigned64 bigints, normalized as below; undefined/null, partial records and coercible objects reject. `fmask` and `sysenterCs` host imports fit unsigned32; STAR's reserved low32 must be0. Pointer fields are canonical48. Constructor validation is atomic with context/paging validation. On linear CPUs reject the constructor field even when explicitly undefined, and reject both methods.

Keep this fixed-size bank a separate projection, rather than adding seven words to every ordinary scalar/run snapshot or per-instruction handover. Preserve existing state offsets and the five-argument generated entry contract; one authoritative layout still owns any new transport fields.

Idle setters capture each field once, validate the whole candidate, recheck lifecycle/run generation after getters, then publish atomically. Detached readbacks cannot mutate the CPU. If a getter starts/completes a run or disposes the CPU, reject the stale outer setter without undoing that nested operation. This does not require a new global epoch for arbitrary nested idle setters; a valid outer capture may subsequently replace the same bank. Pending event/debug sources, SS history, NMI blocking and current CR2 survive a bank repair. `setState`, `setContext`, `setPagingState`, mapping changes and host memory repair preserve this bank. Existing successful `setContext` cancellation rules remain its own contract; do not broaden the stricter bank-setter reentry rule to other APIs.

EFER remains authoritative in `PagingState`; this bank does not contain it. Expand normalized EFER from `0x500/0xd00` to `0x500/0x501/0xd00/0xd01`: SCE(bit0) and NXE(bit11) vary, LME/LMA stay1 and all predecessor fixed/reserved rules remain. WRMSR EFER may set or clear SCE. Its LMA input bit remains read-only/ignored under the predecessor rules. SCE-only writes change subsequent transfer legality; they do not change page permissions or CR2.

FS_BASE and GS_BASE alias the existing loaded `context.segments.fs.base` and `.gs.base`. They are intentionally absent from `FastSystemState`. RDMSR, WRMSR, SWAPGS, full/legacy host context imports and guest segment reloads all observe one authority. A base-only MSR write does not alter the visible selector, type, limit, present/usable state or other attributes. A segment reload has its architectural descriptor/null-selector effects and cannot later resurrect a stale MSR copy. In compatibility mode the full stored base remains observable through RDMSR, while address generation uses the predecessor's low32 effective-base rule. Preserve those loaded facts across CS/submode transitions.

## MSR execution and legality

RDMSR/WRMSR use ECX as the index and CPL0 privilege admission before selected-index/value processing. WRMSR assembles EDX:EAX from their low32 views; unrelated high halves do not enter the value. RDMSR writes zero-extended EAX/EDX results, including in compatibility execution. Selected writes preflight their entire candidate before publication. Reserved/noncanonical failures select #GP(0), with no partial bank/base/context change; normal instruction-begin RF handling is not whole-instruction rollback. LOCK selects #UD. Preserve required-byte fetch and existing admitted prefix policy instead of fetching fictitious ModR/M or operand bytes.

| index                       | authority / accepted guest write                                                       |
| --------------------------- | -------------------------------------------------------------------------------------- |
| `0xc0000080` EFER           | existing paging owner; variable SCE/NXE and fixed LME/LMA rules above                  |
| `0xc0000081` STAR           | entry uses47:32, return uses63:48; low32 reserved0, nonzero guest writes select #GP(0) |
| `0xc0000082` LSTAR          | full canonical48 pointer; no fetch or page probing at write time                       |
| `0xc0000084` FMASK          | low32 flag mask; bits63:32 reserved and rejected on guest write                        |
| `0x174` SYSENTER_CS         | low32 read/write;31:16 retained but unused; guest writes ignore63:32, which read0      |
| `0x175` SYSENTER_ESP        | full canonical48 pointer; no stack probing at write time                               |
| `0x176` SYSENTER_EIP        | full canonical48 pointer; no target probing at write time                              |
| `0xc0000100` FS_BASE        | full canonical48 base in the loaded FS cache                                           |
| `0xc0000101` GS_BASE        | full canonical48 base in the loaded GS cache                                           |
| `0xc0000102` KERNEL_GS_BASE | full canonical48 pointer in the fast-system bank                                       |

Unknown/unselected indices retain the predecessor's private Unsupported frontier; do not turn every unimplemented MSR into an invented architectural #GP. CSTAR, feature reporting, FSGSBASE instructions, LKGS and general MSR virtualization are not added. A zero/null STAR or SYSENTER_CS import is valid storage; each transfer applies its own instruction-specific legality, not a shared selector validator. In particular SYSENTER/SYSEXIT test `SYSENTER_CS[15:2]`, irrespective of retained bits31:16.

## transfer semantics and synthetic caches

Use Intel SDM revision093's non-FRED/non-CET operations. Canonicality is canonical48 throughout. SYSCALL, SYSRET and SWAPGS execute only in Long64; compatibility selects #UD even when SCE=1. SYSENTER/SYSEXIT execute in Long64 and compatibility in this paged profile. Entry instructions may execute at any CPL; return instructions and SWAPGS require CPL0. Runtime feature/CPL/target checks produce typed architectural faults, not private Unsupported. LOCK is #UD. For these five newly selected instructions ignore redundant66/67, segment and F2/F3 prefixes. In Long64 only REX.W selects a 64-bit return, including with66; other REX bits are ignored. Compatibility retains ordinary legacy opcode interpretation of40–4f, not REX. No16-bit fast return is created. RDMSR/WRMSR retain their predecessor REP-prefix Unsupported frontier. Keep unsupported valid forms distinct from malformed encodings and required-fetch failures.

All selector arithmetic is low16 with wrapping, masking and RPL forcing in the instruction's documented order. Preserve the TI bit. These transfers synthesize loaded CS/SS state; they do not consult GDT/LDT/IDT/TSS, validate descriptor contents, set descriptor accessed bits, build a frame or read/write a stack. Do not reuse a descriptor-load path whose side effects differ. Neither a null/out-of-table resulting STAR selector nor a synthetic SS load may accidentally create a MOV-SS shadow.

Synthetic CS has base0, effective limit`0xffffffff`, readable accessed code(type11), S/P/G=1, DPL equal to the destination CPL, and L/D chosen below. Synthetic SS has base0, effective limit`0xffffffff`, writable accessed data(type3), S/P/G/B=1 and destination DPL. Both are usable, nonconforming and available0; SS.long=0. These explicit snapshot values apply even to null-selector outcomes. Other segment caches, descriptor tables, TR/LDTR, numeric state and unmentioned GPRs retain their existing state. In particular do not reuse the ordinary far/IRET outer-return sanitizer that clears lower-privilege DS/ES/FS/GS caches: fast returns preserve them.

| instruction                   | destination / GPR and stack effects                                                                                                                                        | selectors and flags                                                                                                                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SYSCALL `0f05`                | require SCE; RCX=next full RIP, R11=saved architectural flags, RIP=LSTAR; CPL0/Long64; RSP unchanged                                                                       | CS=`STAR[47:32]&0xfffc`, SS=`(STAR[47:32]+8)&0xffff`; CS.L/D=1/0. Apply FMASK after RF clearing and R11 capture; fixed flag bits remain architectural.                                                            |
| SYSRET `0f07`, REX.W variant  | require SCE then CPL0. W: canonical RCX to RIP, Long64; default: zero-extended ECX to RIP, compatibility32. RSP unchanged; RCX/R11 preserved                               | W CS=`(STAR[63:48]+16) OR 3`, default CS=`STAR[63:48] OR 3`; SS=`(STAR[63:48]+8) OR 3`; all low16. CS.L/D=1/0 or0/1. RFLAGS=`(R11&0x3c7fd7) OR 2`, clearing RF/VM/reserved bits without POPF privilege filtering. |
| SYSENTER `0f34`               | require `SYSENTER_CS[15:2]!=0`; CPL0/Long64 from either submode. Full MSR EIP to RIP, ESP to RSP; save no return state                                                     | CS=`SYSENTER_CS[15:0]&0xfffc`, SS=CS+8 low16; CS.L/D=1/0. Clear IF/VM; preserve other defined flags subject to begin RF. Independent of SCE.                                                                      |
| SYSEXIT `0f35`, REX.W variant | require nonnull SYSENTER_CS then CPL0. W: canonical RDX to RIP and RCX to RSP, Long64. Default: zero-extended EDX to RIP and ECX to RSP, compatibility32; preserve RDX/RCX | W CS=`(SYSENTER_CS[15:0]+32) OR 3`, default CS=`(SYSENTER_CS[15:0]+16) OR 3`; SS=CS+8 low16; CS.L/D=1/0 or0/1. Preserve defined flags subject to begin RF. Independent of SCE.                                    |
| SWAPGS `0f01f8`               | require CPL0/Long64; atomically exchange loaded GS.base and KERNEL_GS_BASE; preserve all GPRs and stack                                                                    | preserve selectors/attributes and defined flags subject to begin RF; independent of SCE; no memory access                                                                                                         |

For SYSRET64, a noncanonical RCX faults at the kernel instruction before destination CPL/CS/SS/flags publication. SYSRET32 checks its truncated destination rather than rejecting arbitrary high RCX bits. SYSRET never validates or canonicalizes the unchanged RSP. SYSEXIT64 checks both loaded pointers before publishing either or changing privilege; SYSEXIT32 uses the truncated values. This form-specific SYSEXIT interpretation follows volume3A §6.8.7.1 and volume2B's operation/description; do not apply the latter's unqualified 64-bit-mode exception-table wording to discarded high32 bits. SYSENTER/SYSCALL pointers have already passed MSR canonicality; writes/imports do not test their mapping or execute permission.

The first target instruction fetch is a separate access after a successful transfer. An absent or NX translation, or a supervisor-only target after a CPL3 return, faults under the destination CPL/context with the transfer already retired and committed. CR2 reflects that architectural target-fetch #PF. SMEP remains0: CPL0 entry can fetch either user or supervisor pages when other checks permit. Valid guest translation followed by missing/denied private physical backing instead retains the predecessor's private refusal, unchanged CR2 and no fabricated #PF/error frame. Do not undo entry, redo SWAPGS, fabricate a transfer-time stack access or save the old CPL merely because target decode/translation/compilation later refuses. Conversely a return's own #GP retains its source CPL and source instruction boundary; a handler may repair its operand and IRET retry once.

## boundaries, delivery and executable ownership

Terminate the current generated execution path at a successful transfer before executing bytes under changed CPL/CS/submode. Publish live scalar/flags and numeric state as required by the existing helper handover; do not independently reconstruct flags or address semantics in TypeScript. Each successful transfer/SWAPGS/MSR instruction retires once and consumes ordinary instruction work; it is not an event-entry attempt and does not build an event source. Handler/user fetch, translation refusal, browser compilation, short run resumes and later direct middle-entry execution preserve committed state.

Integrate with the existing producer-typed fault and debug owners. Instruction execute breakpoints precede execution; a transfer-time #UD/#GP suppresses tentative completion causes. Successful transfers have no operand-data accesses to match. Handler/user fetch may independently hit an execute breakpoint or #PF. Entry/return does not implicitly clear DR state, NMI blocking, selected external sources or deferred debug history. Apply existing SS/STI expiration and debug arbitration to actual instruction completion; synthetic SS is not MOV/POP SS and does not arm another shadow. Explicit SWAPGS belongs to guest software; IDT entry/IRET and fast transfers do not silently perform it.

Use ordinary instruction-completion arbitration before post-work budget/stop gates, not software INT's special handler-entry routing. A transfer that consumes the last instruction allowance may still expose a newly eligible pending #DB/NMI/IRQ at its committed destination before a private quota exit; entry itself consumes no automatic-delivery allowance. For example preceding SS suppression expires on a successful SYSENTER before queued NMI selection at its new CPL0 boundary, and SYSRET restoring IF1 can expose a queued IRQ at CPL3. The predecessor's event-attempt budget still bounds actual delivery.

Apply normal instruction-begin RF clearing before SYSCALL captures R11, so saved R11.RF=0. Save the other architectural flags before FMASK and keep fixed bit1=1 after masking. Pin the selected TF completion rule explicitly: SYSCALL and SYSRET use their resulting TF for the BS cause. Thus incoming TF1 plus FMASK.TF1 does not single-step SYSCALL, while FMASK.TF0 does; SYSRET restoring R11.TF1 traps immediately at the returned CPL3 boundary even when incoming TF0, while restoring TF0 produces no BS even when incoming TF1. SYSENTER/SYSEXIT/SWAPGS preserve TF and use ordinary completion. This is distinct from IRET's inherited sampling rule and from any FRED debug-drop rule. The SYSRET restored-TF behavior is independently corroborated by Linux's real return-path restriction cited below; these combinations require explicit literal execution oracles, not a shared generic transfer expectation.

Preserve the predecessor's fault-versus-private-refusal rules and frozen saved fault/trap context. A reported/delivered #DB must identify the committed destination boundary and current privilege; a transfer-time fault must identify the source. Existing SS suppression/deferred aggregation still arbitrates those BS causes. First-destination execution and its own TF/data causes are separate from transfer completion.

Reuse the existing artifact owner and context versioning. Generated code must not bake in mutable STAR/LSTAR/FMASK/entry-pointer/GS values without a tracked dependency. Changed CPL, CS.L/D, effective FS/GS bases and EFER.SCE must affect the next consumer, including retained middle entries and pending browser compilation. A bank update with no generated assumption can be read at execution; it does not require an independent cache. FS/GS-changing WRMSR and SWAPGS must end/revalidate a generated path before a successor using an old embedded base: a version bump alone cannot repair an already running native successor. Use the same context authority/currentness mechanism as segment changes. A SCE-only EFER change is not a page-table/root change; retain current paging dependency rules without adding needless walks or reporting a fabricated CR2 event.

Paging applies to actual subsequent guest loads/stores, kernel/user stack code and target fetches. Apart from their own required instruction fetch, SWAPGS/MSR writes are nonaccessing: they neither walk pages nor set A/D, CR2 or data-watchpoint causes. Memory through the exchanged GS base follows ordinary segmentation, paging, private physical permissions, code alias invalidation and debug matching. User/kernel mapping separation, NX, WP, changed CR3 and existing page sizes remain meaningful. No TLB, privilege bypass or new host-assisted syscall interception is introduced.

## independent acceptance packets

Use public `Cpu` plus actual generated Wasm on Node and Chrome, with Rust tests at state/decode/semantic/transport owners. Freeze literal MSR values, selectors/cache attributes, next IPs, flags, physical bytes and error sources; expected results must not be computed by the implementation's transfer/cache builder. Compare full scalar/context/paging/fast-system/numeric/debug/event/interrupt/continuation state, guarded memory, work and ownership. Keep engine errors and browser/compiler refusals separate from architectural results.

1. **Bank and lifecycle.** Construct with omission, explicit zero/full banks, each missing/invalid field, signed/overflow/noncanonical pointers, hostile getters, getter-started/completed runs, disposal, mutation of detached snapshots and wrong-model calls. Rejected imports publish nothing; nested successful operations remain. Prove scalar/context/paging/mapping imports preserve the other authorities. EFER500/501/d00/d01 round trip; rejected LME/reserved writes remain rejected; SCE set/clear immediately changes SYSCALL/SYSRET legality without changing NXE/CR2 or clearing selected pending sources.
2. **MSR views.** Literal RDMSR/WRMSR packets cover every selected index, both submodes, all-ones high RAX/RDX, arbitrary high RCX, CPL1/2/3, LOCK and unknown/CSTAR indices. STAR=`0x0020000800000000` round trips; changing its low32 to`0x01234567` selects #GP and preserves it. SYSENTER_CS guest input`0xfeedbeef12340008` reads`0x12340008`; input`0x12340000` stores but entry/return selects #GP. Cover FMASK reserved high bits and every pointer at both canonical edges, the first noncanonical value, negative canonical values and unmapped legal addresses. Failed writes preserve every other field and the loaded caches.
3. **SYSCALL64 round trip.** STAR=`0x0020000800000000`, SCE1, LSTAR at supervisor code; user `0f05` saves its literal next IP/flags, enters CS8/SS16 CPL0 with unchanged RSP and no memory/frame/A-D side effects from the transfer itself. FMASK clears selected arithmetic/system/TF/IF bits. Kernel does SWAPGS; GS-relative code saves user RSP and obtains a different kernel stack, performs a guarded memory operation, restores user RSP, SWAPGS and `480f07`. Assert user CS`0x33`, SS`0x2b`, full returned IP, result and exact stack bytes. Program all entry MSRs using guest WRMSR, not only host setup.
   Incoming flags`0x10202` and FMASK0 yield R11=`0x202` and destination FLAGS=`0x202`: RF is cleared before capture.
   Place `0f05` at`0x00007ffffffffffe`: it still enters a canonical LSTAR with saved RCX=`0x0000800000000000`. Do not reject that saved return address during entry; its later SYSRET64 faults in the kernel.
4. **SYSENTER pairs.** From compatibility16/32 and Long64, SYSENTER uses full canonical high-half EIP/ESP and enters Long64 CPL0 with IF0 and no saved return registers. With SYSENTER_CS8, default SYSEXIT gives compatibility32 CS`0x1b`/SS`0x23`, EDX/ECX truncation/zero-extension; REX.W gives Long64 CS`0x2b`/SS`0x33` and full RDX/RCX. Guest stubs preserve their own return state. SCE0 does not disable either path. Include CPL0/1/2 entry and CPL!=0 return denial.
5. **Return widths and preservation.** SYSRET32 returns compatibility32 even from a kernel reached by SYSCALL; high RCX garbage is ignored, RSP is bit-for-bit unchanged and R11 applies the literal0x3c7fd7 mask regardless of IOPL/CPL. Contrast SYSRET64 #GP on the same noncanonical RCX. SYSEXIT64 faults independently for noncanonical target/stack with neither committed; SYSEXIT32 accepts truncated pointers. Include redundant66/67, segment overrides, REX.W and instruction-length page-boundary encodings; no16-bit synthetic code cache. Verify unmentioned GPRs and loaded segments unchanged.
6. **Synthetic caches.** Poison/unmap GDT, LDT, IDT, TSS and both stacks; execute one successful transfer/SWAPGS with budget1, TF0 and empty external queues, stopping before destination fetch/delivery. There must be no implicit table/stack access or descriptor A update. Read back every synthetic CS/SS field, test selector TI/RPL/low16 wrap, STAR null selectors, and SYSENTER low16 null tests. Preserve deliberately lower-privilege-inappropriate DS/ES/FS/GS caches across fast returns. A subsequent ordinary stack/segment operation uses the actual synthetic cache; a later explicit descriptor reload uses the live table and has its own faults.
7. **FS/GS authority.** Context import→RDMSR, WRMSR→context readback→GS/FS-relative memory, SWAPGS twice, and descriptor/null segment reload→RDMSR prove one authority. Also execute straight-line `WRMSR FS_BASE; FS:load` and `SWAPGS; GS:store` without a host return between writer and consumer, then reuse direct middle entries. Use distinct canonical high-half bases with tiny nonidentity physical windows; preserve selector/attributes on MSR/SWAPGS and zero upper32 on a descriptor-loaded base. Compatibility uses low32 for addressing while RDMSR retains the full base until a reload replaces it. Include state images, event entry/IRET and same-value/full context imports without creating another hidden base copy.
8. **Own fault and repair.** SCE0, invalid mode/LOCK, CPL and noncanonical return faults appear at the source RIP with retirement0 and source CPL/cache/flags according to begin semantics. Deliver to a real #UD/#GP handler, repair SCE/RCX/RDX or advance a rejected encoding, and IRET to a single successful continuation. Cover default report and selected processor delivery; no fictitious event allowance or repeated side effects on quota/resume.
9. **Committed target failure.** After successful entry/return, make target translation absent or NX; for CPL3 returns also deny U/S. Assert retirement1 and destination context before failure, literal PF code/CR2 and correct supervisor/user error frames. Positive CPL0-entry controls admit U/S0 and U/S1 targets with SMEP0. Separately deny final private physical X permission/backing: assert the private diagnostic/exit, unchanged CR2 and no fabricated architectural source/frame. Repair PTE/private backing or target bytes and resume without repeating the transfer, restoring RSP again or swapping GS twice. Contrast the source-context SYSRET64 #GP, including guest IST handling when kernel RSP already points at user storage.
10. **Debug and interrupt boundaries.** Combine entry/return/SWAPGS/WRMSR with TF/RF, FMASK.TF/IF, SYSRET-restored TF/IF, execute breakpoints at source and destination, SS-deferred data causes, preceding STI/MOV SS and pending IRQ/NMI. Check before/after quota exhaustion, idle snapshots, report versus delivery, saved full flags and destination privilege. First destination instruction data matching occurs only on its own successful access. A GS-relative debug or page fault does not automatically undo or repeat SWAPGS. Preserve NMI blocking until its existing IRET/host rule releases it.
11. **Currentness and suspension.** Warm ordinary and direct middle entries, change each consumed MSR/FS/GS base/SCE/CR3 through idle APIs or guest execution, and prove no stale target, address or privilege runs. While asynchronous compilation is pending, public reads/setters still reject busy. Separately use the existing paging review's adversarial test-only captured-core/compile hook to change an actual assumed base/context/root before install: reject a stale assumption without authorizing active-run public mutation. Values read dynamically need not invalidate an otherwise current artifact. Same RIP under CPL0/3 or Long64/compatibility is not interchangeable. Guest changes its page root in the kernel, repairs a user page, returns and observes the new mapping. Suspend after every successful transfer and before target fetch/compile; retain exact work/pending sources and reject stale outer host-bank publications.
12. **Inherited consumers and inactive path.** Run existing scalar/REP/LOCK, descriptor/far, numeric/MMX/FX images, debug/external-event and paging-repair packets with the new bank unused and active. Preserve live XMM/x87/MMX/MXCSR state across the new helper handover, sparse image semantics, executable aliases and private physical failures. Linear unsupported frontiers and all existing paged behavior remain separately verified; a passing transfer fixture does not substitute for these consumers.

Mutation proof must kill at least: duplicate FS/GS authority, compatibility SYSCALL acceptance, SCE ignored or accidentally applied to SYSENTER, wrong R11/RFLAGS mask/RF, wrong next RCX, SYSRET32 stack truncation, swapped SYSEXIT RCX/RDX, masked-CS-based SYSCALL SS instead of raw STAR entry+8, source-CPL target fetch, return publication before canonicality, descriptor lookup/A writes during a fast transfer, synthetic SS shadow, eager target/stack probing at MSR write, wrong SYSENTER_CS high/unused bits, stale bank/base after async installation, and replay after committed target failure. Count semantic assertion failures on admitted packets, not crashes/timeouts or test infrastructure refusal.

## implementation and performance boundaries

Follow [architecture](../../agents/architecture.md): x86 owners define MSR rules, transfer effects, synthetic cache facts and faults; context owns loaded FS/GS; paging owns EFER and memory translation; instruction-boundary/debug/event owners publish their existing sources; the existing artifact owner tracks currentness. Embedding adapts state/transport and TypeScript coordinates lifecycle, runs and compilation. Do not put semantics in host glue, duplicate state, create a generic MSR/plugin framework, require unrelated ISA work or prescribe speculative source trees.

Suggested small logical checkpoints: state/API capture and MSR consumers; synthetic cache/transfer semantics and decode; generated lowering and boundary handover; real guest loops with paging/fault/debug/currentness; independent falsification and performance evidence. Each starts with a failing independent packet. These are implementation/commit units, not permission to stop before the whole spec. Keep owner enums/types and captured records in the repository's existing Rust/TypeScript style; dependencies, CI redesign and unrelated refactors are unnecessary. Implementation and commit/push need the separate authorization used by this spec workflow.

Spec-only checks: `npx prettier --check specs/index.md specs/fast-system-transfers/spec.md`, local-link validation and `git diff --check`. Implementation checks: `cargo test --locked`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm test`, `npm run test:browser`; `npm run check` is the complete format/lint/native+Wasm Clippy/Rust/build/Node/Chrome gate. Spec review is not implementation proof.

Freeze exact source `8a7ee067bb9d036b4d19434458706490506ce44a` and shipping core/host hashes for before/after measurements. Reuse all170 inherited report and169 matched-delivery workload groups on Node/Chrome, including debug/descriptor/fault and short-resume controls. Preserve their byte/import/helper/transport/entry/dispatch/resource observations unless a declared semantic change explains a difference. Report core/production-host/module/cache/state sizes and translation/browser compile/instantiation/first/early/later timings. Do not silently use the paging harness's older `c1380a4` default as this spec's baseline.

The20 paging kernels that were current-only for the predecessor are now inherited functionality. Run those same guarded guest packets against both frozen baseline and current, on both runtimes, with explicit per-run/retired-instruction/control/PF/entry denominators and identical rearming. Include their warm/cold leaf A-D, page sizes, root/INVLPG, descriptor/event and PF repair controls; executable/PTE-alias coverage remains separately required by the currentness acceptance packets. The present characterization script is single-build: adapt a small evidence driver or run explicitly paired frozen snapshots; do not present a current-only file as a baseline comparison. Preserve existing outputs, work and owner/helper counts, not just elapsed times.

New fast-transfer kernels have no old supported-instruction baseline. Characterize guarded user/kernel round trips for SYSCALL/SYSRET64, SYSRET32, SYSENTER/SYSEXIT32/64, GS-based stack handover, selected MSR access, and transfer-target PF/handler recovery. Separate instruction/helper/dispatch work, target translation, guest stack switch, run resume and event entry from host rearming. Measure long reuse and short quanta; include active debug and a kernel CR3-change variant. No new unconditional bank poll/helper/spill belongs on unrelated ordinary linear or paged instructions. Reuse the statically selected memory/debug path and existing artifact ownership.

Use balanced before/after order, reversed controls and same-build A/A for replicated absolute costs; retain raw zero/sub-tick samples and runtime versions. Record source, dirty diff, executable hashes, bytes/imports and guarded outputs for every side. Do not expand benchmark unions repeatedly to hide or average away one regression. Synthetic transfer latency does not establish OS-boot capability, hardware cycles, p99, whole-application throughput or an exact remaining spec count.
